OmniSearch viewer is loading...

If this message stays visible, the browser did not start the JavaScript app. The viewer currently imports React and Three.js from https://esm.sh, so an offline browser, blocked CDN, or module-load error can otherwise look like a plain black page.

Serve the folder with python -m http.server -d web, open http://localhost:8000, then check the browser console for the first red module/import error.
